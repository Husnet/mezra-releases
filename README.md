# Mezra – sürümler

Mezra uygulamasının Android dosyaları (APK). Telefonlardaki **Güncelle** düğmesi `version.json` dosyasına bakar
ve yeni sürümü buradan indirir. Bu depoda yalnızca uygulama vardır: çiftlik verisi, şifre veya anahtar yoktur.

Web sürümü (Chrome): https://husnet.github.io/mezra-releases/ — her sürümle birlikte güncellenir.
